POS Advanced Discounts

Controlled percentage and fixed-amount discounts for Odoo 20 Community Point of Sale.

What this module does

POS Advanced Discounts adds a controlled discount workflow while keeping Odoo's native POS order, tax, rounding, invoicing, refund, and session accounting flows.

Key features

  • Apply one percentage or fixed-amount discount to the selected order line.
  • Apply one percentage or fixed-amount discount to the eligible POS order.
  • Configure a maximum percentage and optional maximum fixed amount per POS.
  • Recalculate fixed line discounts safely when quantity changes.
  • Keep discount values through offline storage, synchronization, refunds, and receipts.
  • Validate discount limits server-side before the order is finalized.

How to configure

  1. Install Point of Sale and POS Discount, then install this module.
  2. Open Point of Sale > Configuration > Settings.
  3. Enable Advanced Discounts and set the percentage or fixed-amount limits.
  4. Enable Global Discounts and configure a discount product if order-level discounts are required.

How to use

  1. Select a POS order line and press the native percent control.
  2. Choose Percentage or Fixed Amount and enter the value.
  3. Use the native Discount control for an order-level discount.
  4. Enter zero to remove the active discount.
